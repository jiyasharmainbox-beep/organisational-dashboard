# organisational-dashboard
A simple organisational dashboard for upcoming tasks

# Study Dashboard

## Goal
One place for my sister to see all her assessments, exam dates
and homework, so she never misses a due date.

## Who it's for
My sister, starting high school next year. Mostly used on her laptop.

## Must-have (version 1)
- Add a task (name, subject, type, due date)
- See tasks sorted by due date
- Mark tasks as done
- Delete tasks
- Tasks are still there after refreshing the page

## Nice-to-have (version 2)
- Calendar view
- Colour-coding by subject or type
- Highlight things due in the next 7 days
- Import from Canvas calendar feed
